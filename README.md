# NYURAT - Aplikasi Template Surat

NYURAT adalah aplikasi web berbasis HTML, CSS, dan JavaScript yang menyediakan template surat profesional. Aplikasi ini dirancang untuk membantu pengguna membuat surat resmi dengan format yang benar.

## Fitur Utama

### 1. Beranda Utama
- Tampilan welcome yang menarik dengan informasi tentang aplikasi
- Navigasi yang mudah ke berbagai fitur
- Desain modern dan responsif

### 2. Contoh Surat Benar vs Salah
- Perbandingan visual antara surat yang benar dan salah
- Highlight kesalahan umum dalam penulisan surat
- Pembelajaran interaktif tentang penulisan surat

### 3. 3 Jenis Surat
- **Surat Dinas**: Surat resmi untuk keperluan kedinasan
  - Surat Edaran
  - Surat Keputusan  
  - Surat Perintah
  - Surat Tugas
- **Surat Niaga**: Surat untuk kegiatan bisnis
  - Surat Penawaran
  - Surat Pesanan
  - Surat Perjanjian
  - Surat Klaim
- **Surat Pribadi**: Surat untuk keperluan pribadi
  - Surat Lamaran Kerja
  - Surat Pengalaman Kerja
  - Surat Pernyataan
  - Surat Kuasa

### 4. Template 3 dengan Editor
- Editor seperti Microsoft Word dengan toolbar lengkap
- **Fitur Editing**:
  - Font selection (Times New Roman, Arial, Calibri, Verdana)
  - Font size adjustment
  - Text formatting (Bold, Italic, Underline, Strikethrough)
  - Text alignment (Left, Center, Right, Justify)
  - Lists (Ordered, Unordered, Indent, Outdent)
  - Undo/Redo functionality

- **Fitur Pemeriksaan**:
  - Validasi teks otomatis
  - Auto-correction untuk kesalahan umum
  - Status indikator dokumen
  - Deteksi singkatan dan bahasa slang
  - Pemeriksaan kapitalisasi dan spasi

- **Fitur Export**:
  - Preview dalam jendela baru
  - Print langsung dari browser
  - Download sebagai file HTML
  - Auto-save ke localStorage

## Teknologi yang Digunakan

- **HTML5**: Struktur konten semantik
- **CSS3**: Styling modern dengan animasi dan responsive design
- **JavaScript (ES6+)**: Logika aplikasi dan interaktivitas
- **Font Awesome**: Ikon untuk UI
- **Google Fonts**: Typography (Poppins)

## Cara Penggunaan

1. **Buka Aplikasi**: Buka `index.html` di browser modern
2. **Navigasi**: Gunakan menu navigasi untuk mengakses fitur
3. **Pilih Template**: Pilih template surat yang diinginkan
4. **Edit**: Gunakan editor untuk mengubah konten
5. **Periksa Teks**: Klik tombol Periksa untuk memeriksa kesalahan
6. **Export**: Preview, print, atau download hasilnya
